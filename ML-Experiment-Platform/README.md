# 机器学习实验平台

一个功能完善的机器学习实验平台，支持数据集管理、模型训练、性能评估和可视化展示。

## 项目简介

本项目是一个基于Flask和JavaScript开发的机器学习实验平台，提供了完整的机器学习实验流程，包括：

- **数据集管理**：内置数据集选择、自定义数据集上传
- **智能预处理**：自动数据清洗、特征编码、智能标准化
- **模型训练**：10种经典算法、超参数调优、实时进度监控
- **结果评估**：多指标评估、丰富的可视化展示
- **结果导出**：支持HTML、Markdown、JSON格式导出

## 功能特性

### 支持的算法

**分类算法（7种）**：
- 逻辑回归（Logistic Regression）
- 支持向量机（SVM）
- 决策树（Decision Tree）
- K近邻（KNN）
- 随机森林（Random Forest）
- 梯度提升树（GBDT）
- 朴素贝叶斯（Naive Bayes）

**回归算法（1种）**：
- 线性回归（Linear Regression）

**无监督学习算法（2种）**：
- K均值聚类（K-Means）
- 主成分分析（PCA）

### 核心功能

- ✅ **智能数据预处理**：自动处理缺失值、特征编码、智能标准化
- ✅ **实时训练监控**：WebSocket实时推送训练进度
- ✅ **丰富的可视化**：20+种可视化图表，包括ROC曲线、PR曲线、决策树可视化等
- ✅ **超参数调优**：支持网格搜索和随机搜索
- ✅ **交叉验证**：支持K折交叉验证
- ✅ **算法改进**：实现了拉普拉斯平滑、L2正则化、学习率衰减、决策树剪枝等改进

## 安装步骤

### 环境要求

- Python 3.8+（推荐Python 3.9或3.10）
- 操作系统：Windows 10/11、macOS 10.14+、Linux（Ubuntu 20.04+, CentOS 7+）

### 安装依赖

1. 克隆代码仓库：
```bash
git clone <repository_url>
cd ML-Experiment-Platform
```

2. 创建虚拟环境（推荐）：
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

3. 安装依赖包：
```bash
pip install -r requirements.txt
```

## 使用方法

### 启动服务

```bash
python run.py
```

或者直接运行：
```bash
python src/app.py
```

### 访问平台

启动成功后，在浏览器中访问：
```
http://localhost:5050
```

### 使用流程

1. **数据集载入**
   - 选择内置数据集（从下拉框中选择）
   - 或上传自定义CSV文件（点击"选择CSV文件"按钮）
   - 如果上传自定义文件，选择标签列（目标变量列）

2. **数据预处理**（自动执行）
   - 平台会自动执行智能预处理
   - 包括缺失值处理、特征编码、智能标准化等

3. **数据分割**
   - 选择数据分割方法（随机分割、K折交叉验证等）
   - 设置测试集比例（如果选择随机分割）

4. **模型选择与训练**
   - 选择机器学习算法
   - 配置超参数（可选）
   - 选择评估指标
   - 点击"开始训练"按钮

5. **查看结果**
   - 训练完成后，结果面板会显示性能指标、可视化图表等
   - 可以查看数据预处理信息、混淆矩阵、ROC曲线等

## 常见问题

### 端口被占用

如果5050端口被占用，可以修改 `run.py` 中的端口号：
```python
app.run(host='0.0.0.0', port=5050)  # 修改为其他端口
```

### 数据集格式要求

- CSV格式，第一行为列名
- 目标列建议放在最后一列（系统会自动识别并建议）
- 支持数值型和分类型特征
- 最大文件大小：100MB

### 训练时间较长

某些算法（如GBDT、随机森林）训练时间可能较长，请耐心等待。训练进度会通过WebSocket实时推送。
