## 4. 系统架构设计

本章从**技术实现**角度介绍系统的架构设计，包括系统分层、技术栈、核心模块的技术设计等。

### 4.1 系统架构

平台采用**三层架构**设计，实现前后端分离和模块化：

```
┌─────────────────────────────────────────────────────────┐
│                     前端层 (Frontend)                     │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐             │
│  │ HTML/CSS │  │ JavaScript│ │ Chart.js │             │
│  └──────────┘  └──────────┘  └──────────┘             │
│              WebSocket (SocketIO)                        │
└──────────────────────┬──────────────────────────────────┘
                       │
┌──────────────────────┴──────────────────────────────────┐
│                   后端层 (Backend)                        │
│  ┌──────────────┐  ┌──────────────┐                    │
│  │ Flask API    │  │ SocketIO     │                    │
│  │ - RESTful    │  │ - 实时通信   │                    │
│  │ - 异步处理   │  │ - 进度推送   │                    │
│  └──────────────┘  └──────────────┘                    │
│  ┌──────────────────────────────────────┐            │
│  │ 数据缓存（内存字典，最大10个数据集）    │            │
│  └──────────────────────────────────────┘            │
└──────────────────────┬──────────────────────────────────┘
                       │
┌──────────────────────┴──────────────────────────────────┐
│                 算法层 (Algorithm Layer)                  │
│  ┌──────────────┐  ┌──────────────┐                    │
│  │ 原创算法     │  │ 数据预处理   │                    │
│  │ - 10种算法   │  │ - 特征工程   │                    │
│  │ - 统一接口   │  │ - 数据清洗   │                    │
│  └──────────────┘  └──────────────┘                    │
└─────────────────────────────────────────────────────────┘
```

**架构特点**：
- **前后端分离**：前端负责UI展示和用户交互，后端负责业务逻辑和算法执行
- **异步通信**：使用WebSocket实现实时双向通信，提升用户体验
- **模块化设计**：算法层独立封装，便于扩展和维护
- **统一接口**：所有算法实现统一的fit/predict接口，便于统一管理
- **数据管理**：数据缓存集成在后端层，使用内存字典（`UPLOADED_DATASETS`）实现数据集缓存，最大支持10个数据集

### 4.4 数据流设计

**数据流转过程**：
```
用户上传CSV → 后端解析 → 内存缓存 → 数据预处理 → 模型训练 → 结果评估 → 前端展示
     ↓              ↓           ↓            ↓           ↓          ↓          ↓
  文件验证      类型识别    缓存管理    特征工程    算法执行   指标计算   图表渲染
```

**关键数据流**：
1. **数据集加载**：CSV文件 → pandas DataFrame → 内存缓存
2. **数据预处理**：原始数据 → 缺失值填充 → 特征编码 → 特征缩放 → 预处理后数据
3. **模型训练**：预处理数据 → 数据分割 → 模型训练 → 模型对象
4. **结果评估**：模型对象 + 测试数据 → 预测结果 → 评估指标 → 可视化数据
5. **前端展示**：评估结果 → JSON格式 → WebSocket推送 → 前端渲染

#### 6.3.2 数据预处理（自动执行）
**用户操作**：
- 无需操作，平台自动执行智能预处理

**平台功能**：
数据预处理是机器学习流程中的关键步骤，直接影响模型性能。我们的平台提供了**智能自动预处理**功能，根据算法类型和数据特征自动选择最优的预处理策略：

- **缺失值处理**（自动执行）：
  - **数值型特征**：使用均值填充（SimpleImputer with strategy='mean'）
    - 原理：用该特征的均值替换缺失值
    - 效果：保持数据分布，避免因缺失值导致的样本丢失
  - **分类型特征**：使用众数填充（SimpleImputer with strategy='most_frequent'）
    - 原理：用该特征出现频率最高的值（众数）替换缺失值
    - 效果：保持类别分布，适用于分类特征
  - **智能识别**：自动区分数值型和分类型特征，分别采用合适的填充策略

- **特征编码**（自动执行）：
  - **Label Encoding**：将类别标签转换为整数（如：红→0，绿→1，蓝→2）
    - 应用场景：用于目标变量（y）的编码
  - **One-Hot Encoding**：为每个类别创建二进制列（如：红→[1,0,0]，绿→[0,1,0]）
    - 应用场景：用于特征变量（X）中的分类特征
    - 实现：使用ColumnTransformer自动识别分类特征并进行独热编码

- **特征缩放**（智能判断）：
  - **方法**：StandardScaler标准化（Z-score标准化）
  - **公式**：$z = \frac{x - \mu}{\sigma}$（将数据转换为均值为0、标准差为1的分布）
  - **智能判断逻辑**：
    - **需要标准化的算法**：逻辑回归、线性回归、KNN、朴素贝叶斯
      - 原因：这些算法对特征尺度敏感，标准化可提升性能
    - **不需要标准化的算法**：决策树、随机森林、GBDT
      - 原因：树模型对特征尺度不敏感，无需标准化
    - **SVM特殊处理**：SVM算法内部已进行标准化，无需外部标准化（避免双重标准化）
  - **作用**：消除不同特征之间的量纲差异，提升算法性能

- **预处理信息可视化**：
  - 平台在结果面板中提供"数据预处理信息"卡片，详细展示：
    - 预处理前后对比（样本数、特征数变化）
    - 预处理步骤列表（每个步骤的方法、原因、处理前后的变化）
    - 特征选择详情（如果执行了特征选择，显示选择的特征列表和得分）
    - 数据平衡详情（如果执行了数据平衡，显示平衡前后的类别分布对比）

#### 6.3.3 数据分割
**用户操作**：
1. 选择数据分割方法（随机分割、K折交叉验证等）
2. 设置测试集比例（如果选择随机分割）

**平台功能**：
数据分割是将数据集划分为训练集和测试集的过程，用于模型训练和性能评估：

- **随机分割**：
  - 方法：使用`train_test_split`随机划分训练集和测试集
  - 默认比例：训练集80%，测试集20%（可自定义）
  - 随机种子：支持设置随机种子，确保结果可复现

- **交叉验证**：
  - 方法：K折交叉验证（K-Fold Cross Validation）
  - 支持的K值：3、5、10
  - 原理：将数据分成K份，每次用K-1份训练，1份测试，重复K次，取平均结果
  - 优势：充分利用数据，获得更可靠的性能评估

- **分层采样**：
  - 应用场景：分类任务
  - 原理：保持训练集和测试集中各类别的比例与原始数据集一致
  - 作用：避免因随机分割导致的类别分布偏差，确保评估结果更准确

## 9. 算法原理介绍

### 9.1 分类算法（7种）

**1. 逻辑回归（MyLogisticRegression）**

- **算法原理**：
  - 基于线性回归，通过Sigmoid函数将线性输出映射到[0,1]区间，得到概率预测
  - 使用交叉熵作为损失函数：$L = -\frac{1}{m}\sum_{i=1}^{m}[y_i\log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i)]$
  - 采用梯度下降法优化参数：$w = w - \alpha \frac{\partial L}{\partial w}$
  
- **核心机制**：
  - 通过最大似然估计学习最优分类边界
  - 支持二分类和多分类（One-vs-Rest策略）
  - 二分类：直接使用Sigmoid函数
  - 多分类：为每个类别训练一个二分类器，选择概率最大的类别

- **实现特点**：
  - 支持L2正则化防止过拟合：$L = L_{CE} + \frac{\alpha}{2m}\|w\|^2$
  - 学习率衰减机制提升训练稳定性
  - 支持多分类任务
  - 可记录训练历史（损失曲线、梯度范数）

**📷 需要添加的截图**：
- **逻辑回归训练结果**：展示使用逻辑回归算法训练后的结果界面（性能指标、混淆矩阵等）

**2. 支持向量机(SVM)（MySVM）**

- **算法原理**：
  - 寻找最优分离超平面，最大化分类间隔
  - 优化目标：$\min \frac{1}{2}\|w\|^2 + C\sum_{i=1}^{m}\xi_i$（软间隔）
  - 通过SMO（Sequential Minimal Optimization）算法求解优化问题
  - 支持多种核函数处理非线性分类：
    - **线性核**：$K(x_i, x_j) = x_i^T x_j$
    - **多项式核**：$K(x_i, x_j) = (\gamma x_i^T x_j + r)^d$
    - **RBF核（高斯核）**：$K(x_i, x_j) = \exp(-\gamma\|x_i - x_j\|^2)$

- **核心机制**：
  - 利用支持向量（距离超平面最近的样本点）定义决策边界
  - 通过核技巧将数据映射到高维空间实现非线性分离
  - 支持向量数量通常远少于训练样本数，模型具有稀疏性

- **实现特点**：
  - 自动数据标准化（SVM对数据尺度敏感）
  - 支持多种核函数（线性、多项式、RBF）
  - 采用One-vs-Rest策略支持多分类
  - 可调节正则化参数C控制模型复杂度

**📷 需要添加的截图**：
- **SVM训练结果**：展示使用SVM算法训练后的结果界面（性能指标、混淆矩阵等）

**3. 决策树（MyDecisionTree）**

- **算法原理**：
  - 基于信息增益或基尼不纯度作为分裂准则，递归构建二叉树结构
  - **信息增益**：$IG(D, a) = Ent(D) - \sum_{v=1}^{V}\frac{|D^v|}{|D|}Ent(D^v)$
    - 其中$Ent(D) = -\sum_{k=1}^{|\mathcal{Y}|}p_k\log_2 p_k$（信息熵）
  - **基尼不纯度**：$Gini(D) = 1 - \sum_{k=1}^{|\mathcal{Y}|}p_k^2$
  - 每次分裂选择能最大化信息增益或最小化基尼不纯度的特征

- **核心机制**：
  - 采用ID3/CART算法，通过递归分裂构建决策树
  - 停止条件：
    - 达到最大深度（max_depth）
    - 样本数少于阈值（min_samples_split）
    - 节点不纯度小于阈值（min_impurity_decrease）
    - 所有样本属于同一类别

- **实现特点**：
  - 支持后剪枝（Post-Pruning）防止过拟合
  - 可设置最大深度限制模型复杂度
  - 支持信息增益和基尼不纯度两种分裂准则
  - 提供树结构可视化功能

**4. K近邻(KNN)（MyKNN）**
- **算法原理**：基于实例的学习方法，通过计算新样本与训练样本的距离，选择最近的K个邻居，采用多数投票机制决定分类结果。
- **核心机制**：无需显式训练过程，预测时基于距离度量（欧氏距离、曼哈顿距离等）在特征空间中查找最近邻。
- **实现特点**：支持多种距离度量方式（欧氏距离、曼哈顿距离）、支持距离加权投票、适用于非线性分类问题

**5. 随机森林（MyRandomForest）**
- **算法原理**：Bagging集成学习方法，通过Bootstrap采样生成多个训练子集，每个子集训练一个决策树，最终通过投票机制集成预测结果。
- **核心机制**：每个决策树使用不同的数据子集和特征子集（特征随机选择），通过集成降低方差，提升模型泛化能力。
- **实现特点**：基于自研决策树构建、显著提升模型稳定性和预测准确率、适用于高维数据

**6. 梯度提升树(GBDT)（MyGBDT）**
- **算法原理**：Boosting集成方法，通过顺序训练多个决策树，每个新树专门学习前面所有树的残差，逐步减少预测误差。
- **核心机制**：采用梯度下降思想，每棵树在残差空间上训练，通过累加所有树的预测结果得到最终输出。
- **实现特点**：基于自研决策树、逐步提升模型性能、将多个弱学习器组合成强学习器、对非线性关系有较强建模能力

**7. 朴素贝叶斯（MyNaiveBayes）**
- **算法原理**：基于贝叶斯定理的概率分类器，假设特征之间相互独立（朴素假设）。使用最大后验概率（MAP）进行决策。
- **核心机制**：计算每个类别的先验概率和特征的条件概率，通过贝叶斯定理计算后验概率，选择概率最大的类别作为预测结果。
- **实现特点**：支持拉普拉斯平滑（Laplace Smoothing）处理未见过的特征值、方差稳定性改进防止数值下溢、使用对数似然避免概率相乘导致的数值问题

### 9.2 回归算法（1种）

**8. 线性回归（MyLinearRegression）**

- **算法原理**：
  - 学习特征与目标变量之间的线性关系：$y = w_0 + w_1x_1 + w_2x_2 + ... + w_nx_n$
  - 通过最小化均方误差（MSE）找到最优参数：$MSE = \frac{1}{m}\sum_{i=1}^{m}(y_i - \hat{y}_i)^2$
  - 支持两种求解方法：
    - **闭式解（Normal Equation）**：$w = (X^T X)^{-1} X^T y$（直接计算，适用于小数据集）
    - **梯度下降**：$w = w - \alpha \frac{\partial MSE}{\partial w}$（迭代更新，适用于大数据集）

- **核心机制**：
  - 闭式解通过矩阵运算直接计算最优参数，计算复杂度$O(n^3)$
  - 梯度下降通过迭代更新参数逐步逼近最优解，计算复杂度$O(n^2)$
  - 梯度下降支持学习率衰减，提升收敛速度和稳定性

- **实现特点**：
  - 支持学习率衰减机制优化训练过程
  - 可记录训练历史（损失曲线、梯度范数）用于可视化和分析
  - 提供回归系数可视化，展示各特征对目标变量的影响

### 9.3 无监督学习算法（2种）

**9. K-Means聚类（KMeansModel）**

- **算法原理**：
  - 基于距离的聚类算法，通过迭代优化聚类中心位置
  - 目标函数：最小化样本到所属聚类中心的距离平方和（惯性/Inertia）
  - 优化目标：$\min \sum_{i=1}^{k}\sum_{x \in C_i}\|x - \mu_i\|^2$
    - 其中$C_i$是第i个簇，$\mu_i$是第i个簇的中心

- **核心机制**：
  - **初始化**：随机选择K个样本作为初始聚类中心
  - **分配阶段**：将每个样本分配到距离最近的聚类中心
  - **更新阶段**：根据样本分配重新计算聚类中心位置
  - **迭代**：重复分配和更新阶段，直至聚类中心不再变化或达到最大迭代次数

- **实现特点**：
  - 支持自定义聚类数量K
  - 自动记录聚类惯性（Inertia）评估聚类紧密程度
  - 适用于球形聚类分布
  - 提供聚类结果可视化（2D散点图）

**10. 主成分分析(PCA)（PCAModel）**

- **算法原理**：
  - 基于特征值分解的线性降维算法
  - 通过寻找数据变化最大的方向（主成分）进行投影
  - 保留主要信息的同时降低数据维度
  - 数学原理：
    1. 计算数据的协方差矩阵：$C = \frac{1}{m}X^T X$
    2. 对协方差矩阵进行特征值分解：$C = P\Lambda P^T$
    3. 选择特征值最大的前k个特征向量作为主成分方向
    4. 将数据投影到主成分空间：$Y = XP_k$

- **核心机制**：
  - 计算协方差矩阵并进行特征值分解
  - 选择特征值最大的前k个特征向量作为主成分方向
  - 将数据投影到主成分空间
  - 主成分按解释方差从大到小排序（PC1解释方差最大，PC2次之，以此类推）

- **实现特点**：
  - 支持自定义降维维度
  - 提供解释方差比（Explained Variance Ratio）评估信息保留程度
  - 适用于特征降维和数据可视化
  - 提供降维后数据分布可视化

## 10. 算法改进

### 10.1 朴素贝叶斯改进

#### 10.1.1 拉普拉斯平滑（Laplace Smoothing）
- **改进内容**：
  - 添加 `alpha` 参数（拉普拉斯平滑系数，默认1.0）
  - 在计算类别先验概率时添加平滑项：$P(y) = \frac{N_y + \alpha}{N + \alpha \times C}$
  - 防止某个类别在训练集中未出现时概率为0的问题
- **效果**：
  - 处理训练集中未出现的类别
  - 提升模型泛化能力
  - 避免零概率问题导致的预测失败

#### 10.1.2 方差稳定性改进
- **改进内容**：
  - 添加 `var_smoothing` 参数（默认1e-9）
  - 在计算特征方差时添加平滑项：$\sigma^2 = \sigma^2_{原始} + var\_smoothing$
  - 防止方差为0导致的数值不稳定（如特征值完全相同的情况）
- **效果**：
  - 防止数值计算下溢/上溢
  - 提升计算稳定性
  - 处理特征方差为0的极端情况

#### 10.1.3 对数似然计算优化
- **改进内容**：
  - 使用对数空间计算概率，避免概率相乘导致的数值下溢
  - 使用log-sum-exp技巧进行概率归一化
  - 在预测时使用对数似然而非原始概率
- **效果**：
  - 提升数值计算稳定性
  - 处理小概率乘积问题
  - 避免数值精度损失

### 10.2 逻辑回归改进

#### 10.2.1 L2正则化（Ridge正则化）
- **改进内容**：
  - 添加 `alpha` 参数（L2正则化系数）
  - 损失函数：$L = L_{CE} + \frac{\alpha}{2m} \|w\|^2$
  - 梯度更新：$\frac{\partial L}{\partial w} = \frac{\partial L_{CE}}{\partial w} + \frac{\alpha}{m} w$
- **效果**：
  - 降低过拟合风险
  - 提升模型泛化能力
  - 减少模型复杂度

#### 10.2.2 学习率衰减
- **改进内容**：
  - 支持指数衰减：$lr = lr_0 \times decay^{iteration}$
  - 支持自适应衰减：损失未改善时自动衰减
- **效果**：
  - 提升收敛稳定性
  - 加快训练速度

### 10.3 线性回归改进

#### 10.3.1 学习率衰减
- **改进内容**：
  - 仅在梯度下降模式下生效
  - 支持三种调度策略：`constant`、`decay`、`adaptive`
- **效果**：
  - 提升梯度下降收敛速度
  - 提升训练稳定性

### 10.4 决策树改进

#### 10.4.1 后剪枝（Post-Pruning）
- **改进内容**：
  - 添加 `ccp_alpha`（复杂度参数）和 `min_impurity_decrease`（最小不纯度减少量）
  - 构建完整树后，使用验证集评估是否应该剪枝
  - 如果合并为叶节点能提升验证集准确率，则执行剪枝
- **效果**：
  - 降低过拟合
  - 提升模型泛化能力
  - 减少模型复杂度（树深度减少20-40%）
  - 提升模型可解释性
